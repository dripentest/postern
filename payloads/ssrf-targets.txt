# ssrf-targets.txt
# Значения для вставки в место FUZZ (URL-параметр, body и т.п.) в режиме -mode ssrf.
# Плейсхолдеры, которые движок подставляет на лету:
#   {{OOB}}    -> твой interactsh-домен (с уникальным префиксом на каждый payload)
#   {{LHOST}}  -> твой IP/домен для redirect-трюков (флаг -lhost)
#   {{TARGET}} -> внутренний IP, который хочешь обернуть (флаг -itarget), по умолчанию 127.0.0.1
# Строки с # и пустые игнорируются.
