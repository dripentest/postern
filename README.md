# ssrfuzz

Fuzzing-тулкит на Go для проверки **SSRF** и **Host-Header** атак в рамках авторизованного тестирования (pentest / bug bounty в scope / TryHackMe-лабы).

> ⚠️ **Только для авторизованного тестирования.** Используй исключительно против систем, на тестирование которых у тебя есть явное разрешение (подписанный scope, программа bug bounty, собственная инфраструктура, учебные лаборатории). Автор инструмента не несёт ответственности за неправомерное использование.

## Возможности

- **Raw-request** на вход (сохранённый из Burp «Copy to file»), полный контроль над заголовками
- Режимы: `ssrf`, `host`, `both`
- Фазз параметра по имени (`-p imageUrl`) или по маркеру `FUZZ`
- Исчерпывающие payload-листы: localhost-байпасы, IP-кодировки (dec/oct/hex/IPv6), облачная metadata (AWS/GCP/Azure/DO/Alibaba/OCI/k8s), опасные схемы (`file`/`gopher`/`dict`/...), redirect + DNS-rebinding
- Детекция: diff от baseline (код/длина/тело) + сигнатуры в теле + blind через interactsh (OOB)
- Контроль нагрузки: `-rate` (req/s), `-c` (воркеры), `-delay`/`-jitter`
- Прокси в Burp (`-proxy`)

## Payload-файлы

Лежат в `payloads/`, редактируются без пересборки. Плейсхолдеры: `{{OOB}}`, `{{LHOST}}`, `{{TARGET}}`.
